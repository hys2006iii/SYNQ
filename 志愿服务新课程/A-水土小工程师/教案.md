# 水土小工程师：迷你农场建造赛 — 教案

## 教学信息

- **活动名称**：水土小工程师：迷你农场建造赛
- **活动时长**：60分钟
- **适合年龄**：5-12岁
- **班级规模**：20-30人，分4-5组
- **教学形式**：讲授+实验+竞赛

---

## 第0-5分钟 | 开场导入：小农夫的烦恼

### 教师话术（逐字稿）

"小朋友们好！欢迎来到水韵农青科技课堂！我是今天的主讲老师，大家可以叫我XX老师。"

（停顿，等待回应）

"在开始今天的活动之前，老师想先给大家讲一个小故事。从前啊，有一个小农夫，他有一片大大的农场。可是他遇到了一个大难题——他种的菜总是长不好！有的叶子黄了，有的枯萎了，有的根本发不了芽。小朋友们，你们猜猜看，小农夫的农场出了什么问题呢？"

（等待小朋友回答，引导说出土壤、水、阳光等关键词）

"哇，小朋友们真聪明！小农夫的农场确实出了问题。首先，他不知道自己的土壤适合种什么；其次，他不知道怎么给菜地浇水；最后，他不知道怎么规划自己的农场。所以今天，我们就要化身'水土小工程师'，帮助小农夫解决这些难题！"

"今天的活动特别有趣，我们要完成三个任务：第一，给土壤做体检；第二，设计水渠引水；第三，安装滴灌系统。最后，我们要进行一场农场建造大赛，看看哪个小组建造的农场最棒！"

### 操作步骤

**教师做什么**：
1. 微笑着迎接小朋友，建立亲切感
2. 用生动的语言讲述"小农夫"故事
3. 通过提问互动，激发小朋友的兴趣
4. 介绍今天的三个任务和竞赛机制

**学生做什么**：
1. 找到自己的座位，坐好
2. 认真听故事，积极回答问题
3. 了解今天的活动内容

## 第5-17分钟 | 第一站·土壤体检

### 教师话术（逐字稿）

"小朋友们，我们每天踩在脚下的土地，你们知道它是由什么组成的吗？"

（等待回答）

"土壤啊，其实是由三种东西组成的。第一种是矿物质，就是我们看到的沙子、黏土这些东西，它们是土壤的'骨头'；第二种是有机质，就是腐烂的树叶、小虫子的尸体，它们是土壤的'食物'；第三种是水和空气，它们住在土壤的'缝隙'里。"

"不同的土壤，这三种东西的比例不一样。有的土沙子多，我们叫它沙土；有的土黏土多，我们叫它黏土；还有的土沙子和黏土差不多，我们叫它壤土。今天我们要用到的土壤就是壤土，最适合种庄稼！"

"接下来，老师要教大家一个科学小实验——测土壤的pH值。pH值是什么意思呢？就是测土壤是酸的还是碱的。就像我们吃的柠檬是酸的，肥皂水是碱的，不同的植物喜欢不同酸碱度的土壤。"

（演示pH试纸使用方法）

"大家看，这是pH试纸。我们用滴管取一点土壤浸出液，滴在试纸上，然后和比色卡对比，就能知道土壤是酸性还是碱性啦！"

### 操作步骤

**教师做什么**：
1. 展示土壤样本，讲解土壤三大成分
2. 演示pH试纸的使用方法
3. 分发实验材料（每个小组一份）
4. 巡回指导，确保安全操作

**学生做什么**：
1. 观察土壤样本，触摸感受不同质地
2. 学习pH试纸的使用方法
3. 动手操作：取土壤样本→加水搅拌→静置→用滴管取上清液→滴在pH试纸上
4. 对比比色卡，记录土壤pH值
5. 在学习单上记录实验结果

## 第17-30分钟 | 第二站·水渠设计

### 教师话术（逐字稿）

"小朋友们，我们刚才检测了土壤，现在小农夫需要水来浇灌他的庄稼。可是水从哪里来呢？在古代，农民伯伯们会挖水渠，把河里的水引到田地里。今天，我们也要来设计水渠！"

"设计水渠有一个非常重要的原理，那就是——坡度。小朋友们，你们知道什么是坡度吗？"

（用手比划）

"坡度就是地面倾斜的程度。如果地面是平的，水就不会流动；如果地面太陡，水就会流得太快。所以我们要找到一个合适的坡度，让水慢慢流到农场里。"

"接下来，我们要用纸板和锡纸来搭建水渠。纸板是水渠的骨架，锡纸是防水层。大家先在沙盘里堆出一个有坡度的小山坡，然后用纸板围成水渠的形状，最后铺上锡纸，这样水就不会漏下去啦！"

（演示搭建过程）

"大家注意，水渠要从高处开始，慢慢倾斜到低处，这样水才能自然流动。如果水渠坡度不够，水就流不动；如果坡度太陡，水就会冲坏农场。"

### 操作步骤

**教师做什么**：
1. 讲解坡度原理，用生活中的例子说明
2. 演示水渠搭建方法
3. 分发材料（纸板、锡纸、胶带等）
4. 巡回指导，帮助各组调整坡度

**学生做什么**：
1. 听讲坡度原理，理解水流与坡度的关系
2. 在沙盘里堆出有坡度的小山坡
3. 用纸板围成水渠形状
4. 铺上锡纸，确保防水
5. 用蓝色颜料模拟水流，测试水渠是否通畅

## 第30-45分钟 | 第三站·滴灌安装

### 教师话术（逐字稿）

"小朋友们，你们知道吗？如果用普通的浇水方式，大部分水都流走了，真正被植物吸收的只有很少一部分。但是有一种神奇的浇水方式，可以让水一滴一滴地流到植物的根部，这就是——滴灌！"

"滴灌是怎么工作的呢？大家看，这是一个塑料瓶，我们在瓶盖上扎几个小孔，插上吸管，然后装满水。当我们把瓶子倒过来，水就会沿着吸管一滴一滴地流出来。如果我们把吸管的另一端放在植物的根部，植物就能喝到刚刚好的水啦！"

（演示滴灌装置制作）

"现在，大家要用矿泉水瓶、吸管和胶带来制作滴灌装置。首先，在瓶盖上扎孔——这个由助教老师来帮忙，大家不要自己扎，小心受伤。然后把吸管插进去，用胶带固定好。最后，把滴灌装置安装到沙盘农场里。"

"安装好之后，我们往瓶子里加水，观察水是不是真的能一滴一滴地流出来。如果流得太快，我们可以用胶带把吸管口封小一点；如果流得太慢，我们可以把孔扎大一点。"

### 操作步骤

**教师做什么**：
1. 讲解滴灌原理，强调节水的重要性
2. 演示滴灌装置制作过程
3. 指导助教帮助小朋友扎孔（安全操作）
4. 分发材料，巡回指导制作
5. 指导各组调试滴灌系统

**学生做什么**：
1. 听讲滴灌原理，理解节水灌溉的意义
2. 观察教师演示，学习制作方法
3. 动手制作滴灌装置（在助教协助下完成扎孔步骤）
4. 安装滴灌装置到沙盘农场
5. 加水测试，调整滴灌速度

## 第45-55分钟 | 终极挑战：竞赛评比

### 教师话术（逐字稿）

"好，小朋友们，现在进入终极挑战环节！在这个环节，我们要做三件事：第一，测试你们的农场系统；第二，装饰你们的农场；第三，进行评比。"

"首先，测试系统。大家往水渠里倒水，看看水能不能顺利流到农场里。然后，往滴灌装置里加水，看看水能不能滴到植物根部。如果发现问题，现在赶紧调整！"

"其次，装饰农场。用我们准备的仿真植物、黏土小动物等，把你们的农场装扮得漂漂亮亮的。可以在海报上画出农场的名字和介绍。"

"最后，评比环节。每个小组派一个代表，用一分钟时间介绍你们的农场：叫什么名字？有什么特色？你们是怎么设计的？然后，我们根据四个标准来打分：系统是否通畅、设计是否合理、农场是否美观、团队是否协作。"

（倒计时5分钟，巡回指导）

"时间到！现在开始展示环节。请第一组派代表上台介绍你们的农场..."

### 操作步骤

**教师做什么**：

3. 组织装饰环节

4. 派代表上台展示（1分钟/组）
5. 观看其他组展示，学习借鉴

## 教学提示

### 分龄教学建议

| 年龄段 | 教学调整 |
|--------|----------|
| **5-6岁（幼儿）** | 简化理论讲解，增加动手操作时间；使用更生动的语言和道具；助教全程陪同指导 |
| **7-9岁（低年级）** | 适当讲解原理，鼓励自主探索；设置小组长角色，培养领导力 |
| **10-12岁（高年级）** | 深入讲解工程原理，鼓励创新设计；可增加计算坡度等数学内容 |

### 常见问题应对

| 问题 | 应对方法 |
|------|----------|
| 小朋友注意力不集中 | 用提问互动、小奖励等方式吸引注意 |
| 材料不够用 | 提前准备备用材料，引导小朋友分享 |
| 小朋友受伤 | 立即处理伤口，安抚情绪，必要时联系家长 |
| 系统调试失败 | 助教协助调试，鼓励小朋友不要放弃 |
| 时间不够用 | 灵活调整环节时长，确保核心内容完成 |
