# 土壤侦探社：破解大地密码 —— 教案

## 课程信息

| 项目 | 内容 |
|------|------|
| 课程名称 | 土壤侦探社：破解大地密码 |
| 适用对象 | 4-10岁幼儿及小学生 |
| 课程时长 | 60分钟 |
| 课程人数 | 20-30人 |
| 教学场地 | 科技馆活动教室 |

---

## 第0-5分钟 | 开场导入：侦探社成立！

### 教师话术

"小朋友们好！欢迎来到我们的'土壤侦探社'！我是这里的侦探社社长，你们可以叫我——社长老师！"

"今天，我们收到了一个紧急报案！有一位神秘的委托人告诉我们——大地生病了！泥土变得枯黄，植物都垂头丧气，小动物们找不到干净的土壤安家……"

"要破解这个谜案，我们需要一群勇敢的小侦探！你们愿意加入侦探社，帮大地找出病因吗？"

"好！现在我宣布——土壤侦探社，正式成立！在开始破案之前，每位小侦探都会获得一枚侦探徽章！请助教老师为每位小侦探颁发徽章。"

### 操作步骤
1. 主讲教师站在教室前方，用神秘、夸张的语气开场
2. 助教依次为每位学生佩戴侦探徽章贴纸
3. 强调侦探的"三大守则"：认真观察、积极思考、团结协作

### PPT切换提示

- 第2页：侦探社成立仪式，配图侦探帽、放大镜元素

### 过渡语

"侦探社已经成立了！但是要破案，我们需要线索。接下来，我们要去案发现场——土壤里，寻找第一条线索！准备好了吗？出发！"

---

## 第5-17分钟 | 线索1：土壤真面目

### 教师话术

"小侦探们，我们来到了案发现场！土壤看起来黑乎乎的，但是你们知道吗？土壤其实是'三合一'的神秘混合物！"

"第一种成分是**矿物质**——这是土壤的'骨架'，就像我们身体里的骨头一样。矿物质来自岩石的风化，有的粗有的细，粗的叫'沙'，细的叫'黏土'。"

"第二种成分是**有机质**——这是土壤的'营养品'，就像我们吃的蔬菜水果。有机质来自落叶、枯枝、小虫子的尸体，它们腐烂后变成黑色的腐殖质，给土壤提供养分。"

"第三种成分是**水和空气**——这是土壤的'呼吸'。土壤里有小缝隙，水和空气就在里面'游泳'和'散步'。没有水，植物会渴死；没有空气，植物的根会憋死。"

"现在，我们要用一个神奇的实验来验证土壤的'三合一'配方！这个实验叫做——**量筒沉降分层实验**！"

### 实验操作指导

**材料：** 量筒、三种土壤样本、水、搅拌棒

**步骤：**
1. 每组发一个量筒，装入约1/3的土壤样本
2. 加入清水至量筒的3/4处
3. 用搅拌棒用力搅拌1分钟
4. 静置观察，看土壤分层现象

**引导观察：**
- "大家看！量筒里发生了什么？是不是出现了分层？"
- "最底下那层厚厚的，是什么？——对了，是矿物质！重的先沉下去！"
- "中间那层黑黑的、飘来飘去的，是什么？——是有机质！"
- "最上面那层水变浑浊了，里面有小气泡，说明了什么？——有空气和细小的颗粒！"

- 第3页：土壤成分示意图（矿物质、有机质、水和空气）
- 第4页：量筒沉降分层实验步骤图解

### 过渡语

"恭喜各位小侦探！你们成功破解了第一条线索——土壤的真面目！现在，请助教老师为每组颁发**线索卡1号**！集齐四张线索卡，我们就能揭开'大地生病'的真相！"

**（助教分发线索卡1号）**

"但是，土壤还有更多秘密等着我们去发现。接下来，我们要检测土壤的'酸甜苦辣'——土壤也有味道吗？走，去看看！"

---

## 第17-29分钟 | 线索2：土壤的酸甜苦辣

### 教师话术

"小侦探们，你们尝过酸酸的柠檬、甜甜的糖果、苦苦的药片吗？其实，土壤也有自己的'味道'——不过不是用舌头尝，而是用科学仪器来测！"

"土壤的'味道'叫做**酸碱度**，用pH值来表示。pH值就像土壤的'心情指数'：pH等于7是'中性'，心情刚刚好；pH小于7是'酸性'，心情有点酸溜溜；pH大于7是'碱性'，心情有点涩涩的。"

"不同的植物喜欢不同的'心情'。比如，蓝莓喜欢酸性土壤，仙人掌喜欢碱性土壤。如果土壤'心情'不好，植物就会长得不好，这就是'大地生病'的原因之一！"

"现在，我们要用**pH试纸**来检测土壤的'心情'！这是一种神奇的试纸，遇到不同酸碱度的土壤，会变成不同的颜色！"

### 实验操作指导

**材料：** pH试纸、透明杯、滴管、三种土壤样本、蒸馏水、标准比色卡

**步骤：**
1. 每组发一个透明杯，装入一勺土壤样本
2. 加入适量蒸馏水，搅拌成泥浆
3. 用滴管吸取上层清液，滴在pH试纸上
4. 等待30秒，观察试纸颜色变化
5. 对照标准比色卡，读出pH值

**引导观察：**
- "大家看！试纸变成了什么颜色？对照比色卡，我们的土壤pH值是多少？"
- "沙土的pH是多少？黏土呢？混合土呢？有什么不同？"
- "如果pH值太低（太酸）或太高（太碱），植物会怎么样？"

### 过渡语

"太棒了！小侦探们又破解了一条线索！现在请助教老师颁发**线索卡2号**！"

**（助教分发线索卡2号）**

"我们已经知道土壤的真面目，也测出了土壤的'心情'。但是，土壤还有一个重要的能力——喝水！有的土壤喝得快，有的喝得慢。接下来，我们要让三种土壤来一场'喝水比赛'！"

---

## 第29-42分钟 | 线索3：土壤喝水比赛

### 教师话术

"小侦探们，你们知道植物是怎么喝水的吗？是通过根从土壤里'吸'上来的！但是，不同的土壤'保水能力'不一样。"

"**沙土**颗粒大、缝隙大，水会很快漏走，就像一个漏水的筛子，保水能力差。"

"**黏土**颗粒小、缝隙小，水很难漏走，就像一个密封的瓶子，保水能力太强，有时候反而会把植物的根泡烂。"

"**混合土**（沙土+黏土）颗粒大小搭配合理，缝隙适中，既能留住足够的水，又不会太湿，保水能力最好！"

"现在，我们要让三种土壤来一场**喝水比赛**！比赛规则是：每组给三种土壤浇同样多的水，看谁漏得最快、谁漏得最慢，用计时器记录时间！准备好了吗？比赛开始！"

### 实验操作指导

**材料：** 三个透明杯、沙土、黏土、混合土、量杯、水、计时器、纸巾

**步骤：**
1. 每组准备三个透明杯，分别装入等量的沙土、黏土、混合土
2. 杯子底部垫纸巾（观察漏水情况）
3. 同时向三个杯子倒入等量的水（约50ml）
4. 开始计时，观察哪个杯子底部最先渗水
5. 记录三种土壤渗水的时间

**引导观察：**
- "哪个杯子最先漏水？（应该是沙土）"
- "哪个杯子最后漏水？（应该是黏土）"
- "哪个杯子的保水效果最好？（应该是混合土）"
- "这说明了什么？——混合土最适合植物生长！"

"精彩的比赛！小侦探们发现了重要线索——不同土壤的保水能力不一样！现在请助教老师颁发**线索卡3号**！"

**（助教分发线索卡3号）**

"我们已经收集了三条线索：土壤的成分、土壤的酸碱度、土壤的保水性。现在，我们有了足够的证据来分析'大地生病'的原因！但是，光找到病因还不够，我们还要开出'药方'——也就是土壤改良的方法！这是我们的**终极线索**！"

## 第42-52分钟 | 终极线索：开药方

### 教师话术

"小侦探们，经过前面的调查，我们已经掌握了四条线索。现在，我们要综合分析，找出'大地生病'的真正原因，并且开出能够治好大地的'药方'！"

"回顾一下我们的线索：
1. 土壤由矿物质、有机质、水和空气组成
2. 土壤有酸碱度，不同植物需要不同的pH环境
3. 沙土保水差、黏土保水太强、混合土最合适

所以，'大地生病'的原因可能是：
- 土壤太酸或太碱，植物'心情'不好
- 土壤保水能力差，植物喝不到水
- 土壤缺少有机质，植物没有营养

针对这些病因，我们可以开出什么'药方'呢？"

### 小组讨论引导

**讨论问题：**
1. 如果土壤太酸了，可以用什么方法改良？
2. 如果土壤太碱了，可以用什么方法改良？
3. 如果土壤保水能力差，可以怎么做？
4. 如果土壤缺少营养，可以添加什么？

**改良方法提示（PPT展示）：**
- 太酸 → 加石灰、草木灰（中和酸性）
- 太碱 → 加硫磺粉、腐叶土（降低碱性）
- 保水差 → 加黏土、有机质（改善结构）
- 缺营养 → 加腐熟农家肥、堆肥（补充有机质）

### 药方海报制作

**材料：** 大海报纸、彩笔

**要求：**
1. 海报标题："大地药方"
2. 写出诊断出的"病因"（至少2个）
3. 写出对应的"药方"（至少2个）
4. 画上插图（可以是植物、土壤、工具等）
5. 小组成员签名

**时间：** 8分钟
