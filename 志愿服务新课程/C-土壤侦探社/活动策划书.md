# 土壤侦探社：破解大地密码 —— 活动策划书

## 一、活动背景

河海大学农业科学与工程学院「水韵农青」志愿服务队，长期致力于农业科学知识的普及与传播。本次志愿服务课程依托学院土地整治工程专业优势，将专业的土壤检测、土壤改良知识转化为青少年易于理解的趣味内容。

我们创新性地采用"侦探破案"的叙事驱动模式，让孩子们化身"土壤小侦探"，通过收集线索、破解谜题的方式，层层揭开"大地生病"的真相。这种沉浸式的学习体验不仅能激发孩子们的好奇心和探索欲，更能在潜移默化中传递土壤保护的科学理念。

## 二、活动目标

### 知识目标
1. 了解土壤的三大组成成分（矿物质、有机质、空气和水分）
2. 学会使用pH试纸检测土壤酸碱度
3. 理解不同土壤类型（沙土、黏土、混合土）的保水性差异
4. 初步了解土壤改良的基本方法

### 能力目标
1. 培养观察、记录、分析的科学探究能力
2. 提升小组协作与沟通表达能力
3. 锻炼动手实验操作能力

### 情感目标
1. 激发对土壤科学的好奇心和探索兴趣
2. 培养保护土壤、珍惜土地资源的环保意识
3. 体验团队合作解决问题的成就感

## 七、安全预案

### 1. 场地安全
- 活动前检查教室电源、桌椅等设施安全
- 确保通道畅通，紧急出口标识清晰
- 准备急救箱（创可贴、消毒棉签等）

### 2. 材料安全
- 所有土壤样本提前消毒处理，确保无尖锐物、无污染
- pH试纸为安全级别，不具有腐蚀性
- 禁止学生品尝任何实验材料
- 实验过程中佩戴一次性手套

### 3. 人员安全
- 助教全程巡视，确保学生正确使用实验器材
- 量筒等玻璃器皿使用前检查有无破损
- 学生分组活动时，每组至少1名助教看护
- 如有学生出现不适，立即停止活动并通知家长

### 4. 突发情况处理
- **材料打翻**：立即用纸巾清理，湿滑区域放置警示标识
- **学生冲突**：助教及时介入调解，引导合作
- **学生身体不适**：转移至通风处休息，必要时联系场馆医疗点
- **设备故障**：备用材料提前准备，确保活动可继续进行

## 八、专业壁垒说明

本课程的专业壁垒体现在以下方面：

### 1. 知识转化壁垒
土壤学是农业科学的重要分支，涉及土壤物理、土壤化学、土壤生态等多个专业方向。将专业的土壤检测技术（如pH测定、质地分析）转化为4-10岁儿童能够理解的语言和操作，需要深厚的学科功底和丰富的科普经验。

### 2. 实验设计壁垒
量筒沉降分层实验、pH试纸检测、土壤渗透对比实验等，都需要经过专业设计和反复验证，确保实验现象明显、操作简单、结果可重复。实验材料的配比、操作步骤的优化都需要专业知识支撑。

### 3. 课程整合壁垒
将土壤科学知识、侦探叙事、小组竞赛、动手实验等多种元素有机融合，设计出既有知识深度又有趣味性的60分钟课程，需要系统的课程设计能力和丰富的教学经验。

### 4. 专业背书壁垒
本课程由河海大学农业科学与工程学院「水韵农青」志愿服务队出品，依托土地整治工程专业优势，具有高校专业背景背书，区别于一般的科普活动。
